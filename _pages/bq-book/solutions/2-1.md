The Monte Carlo estimate is

$$
\mathbb{E}[X^2] \approx \frac{1}{n} \sum_{i=1}^n x_i^2, \qquad x_i \sim \mathcal{N}(0, 1).
$$

```python
import numpy as np

rng = np.random.default_rng(seed=0)
x = rng.standard_normal(1000)
print(np.mean(x**2))  # close to the true value 1
```
